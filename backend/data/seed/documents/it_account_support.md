# IT Account and Access Support

If you cannot access your account, email, or internal tools, first use the password reset or account recovery option provided on the company sign-in page.

If the reset does not work, submit an IT support ticket through the internal help desk and include your employee ID, affected system, and a short description of the issue.

Requests for new system access or device setup still require manager approval when the requested permission is not part of the standard onboarding access bundle.
